# Защита NOVA: 3–5 минут

## 1. Pitch — около минуты

NOVA — минималистичный магазин повседневной техники. Пользователь хочет быстро найти товар, изучить его характеристики и сохранить понравившиеся вещи. В MVP уже работают каталог, поиск, категории, избранное, профиль и корзина. Дальше можно подключить REST API каталога, базу данных и BLoC.

## 2. Live demo — около двух минут

1. Покажи Feed, прокрути четыре карточки, проверь поиск и категории.
2. Открой любой товар. Объясни, что Navigator.push передаёт целый объект Product.
3. Нажми bookmark, измени количество и добавь товар в корзину. Прокрути экран: Add to Cart остаётся снизу.
4. Вернись через стрелку AppBar. Открой Favorites: сохранённый товар уже там.
5. Открой его ещё раз и вернись через Back to collection внутри страницы.
6. Открой корзину, покажи варианты товара, количество и сумму. Пройди demo checkout: оплата не списывается, чек появится в My orders.
7. В Profile открой Create your profile. Отправь пустую форму, покажи ошибки.
8. Заполни имя, email и пароли; выбери роль. Без галочки Terms отправка запрещена. Поставь галочку и создай профиль: появится SnackBar и имя в Profile.

Демо-данные: Student Demo / student@narxoz.kz / demo123 для обоих паролей.

## 3. Code review — около минуты

Открой lib/main.dart. Покажи Product, RootScreen, DetailScreen и RegistrationScreen. Найди Navigator.push, Navigator.pop, setState, IndexedStack, Stack, Row, Wrap, Expanded и GlobalKey<FormState>. Все экраны находятся в одном файле по требованию этой версии; классы уже разделены логически для дальнейшего переноса по папкам Capstone.

Покажи результаты flutter analyze и flutter test. Для адаптивности поменяй ориентацию или размер окна: узкая версия использует Column, широкая — Row с Expanded; контент прокручивается, кнопка закреплена в SafeArea.

## Короткая запись для сдачи — 45–90 секунд

Готовая запись переходов находится в Demo/nova-walkthrough.mp4. На этом компьютере запускай NOVA_Demo из Android Studio → Device Manager: приложение уже установлено. Старый Medium_Phone_API_36.1 сохранён, но в нём были ошибки System UI и хранилища.

Запусти запись экрана телефона/эмулятора. Последовательно покажи Feed → Detail → bookmark → Add to Cart → Back → Favorites → Detail → in-body Back → Profile → Registration → успешное создание. Останови запись и приложи MP4 либо ссылку рядом со ссылкой на GitHub.

## Границы Milestone 1

Профиль, избранное, корзина, история demo-заказов и выбранная тема сохраняются на устройстве через shared_preferences и восстанавливаются после перезапуска. Регистрации на сервере, облачной синхронизации, оплаты и реальных push-уведомлений пока нет. Пароль не сохраняется и скрыт в debug-выводе. Покажи переключение Light / Dark в Profile и анимации переходов, bookmark и Add to Cart.

Это Flutter-проект. Проверка сборки и запуска выполнена на Windows/Android; для iOS нужны macOS и Xcode. Все экраны оставлены в одном main.dart по запросу; для требования Capstone о папках lib/screens и lib/widgets потребуется отдельный этап реорганизации.
