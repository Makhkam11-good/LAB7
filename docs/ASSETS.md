# Фотографии и ресурсы NOVA

Активный каталог использует реальные фотографии, скачанные с Unsplash 28 октября 2026 года. Файлы включены в assets/photos, поэтому карточки работают без сети. Никакие новые изображения для этого этапа не генерировались.

[Условия Unsplash](https://unsplash.com/license). Загруженные версии: JPEG, ширина 1000 px, качество 85. Изображения служат иллюстрациями учебного каталога; демонстрационные цены, варианты и характеристики не являются предложением реальных изображённых брендов.

Монограмма NOVA нарисована Flutter Canvas в widgets/components.dart. Roboto включён с лицензией в assets/fonts/LICENSE.txt.

Ранее сгенерированные PNG в assets/images сохранены исключительно для совместимости со старыми снимками заказов в локальном хранилище. Текущие seed-товары и новые поступления используют assets/photos. Старое видео nova-walkthrough.mp4 демонстрирует предыдущую версию Labs 5–7.
